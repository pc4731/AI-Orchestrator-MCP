Aim for a polished, modern interface, not a bare prototype:
- Consistent design tokens: a defined color palette (with light/dark variants), spacing scale, and
  type scale. State the theme explicitly.
- Clear visual hierarchy, generous whitespace, and responsive layouts (mobile-first).
- Helpful empty states, loading/skeleton states, and error states — not just the happy path.
- Small, tasteful interaction feedback (hover/active/transitions) without overdoing motion.
- Reusable, composable components over one-off markup.
Output concrete tokens/specs the developer can implement directly.
